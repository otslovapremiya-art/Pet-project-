## Что делаем следующим шагом

**Шаг 0 из плана — сетап.** По порядку:

1. Vitalii устанавливает git и проверяет, что команда отвечает.
2. Vitalii создаёт аккаунт GitHub и **публичный** репозиторий.
3. Первый коммит — с этими документами.
4. **Тестовый откат:** нарочно сломать файл и вернуть обратно. Не для галочки — страховка должна быть проверена, а не только настроена.

Только после этого — шаг 1 плана.
